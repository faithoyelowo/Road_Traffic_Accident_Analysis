# Road Traffic Accident Insights Dashboard

## Project Overview
This project analyses road traffic accident data using SQL and Power BI to identify patterns and provide insights into accident occurrences, weather conditions, and accident severity.

## Objectives
- Analyse the total number of road traffic accidents.
- Examine accidents across different weather conditions.
- Understand the distribution of accidents by severity.
- Present key findings through an interactive Power BI dashboard.

## Tools Used
- SQL – Data querying and analysis.
- Microsoft Power BI – Data visualization and dashboard development.

## Key Analysis
The dashboard focuses on:
- Total Number of Accidents
- Accidents by Weather Conditions
- Accidents by Severity
